# Site Architecture

Initial release can be a single-page site with anchors.

1. Header — compact logo/wordmark, Menu, Fruit Chaat, Chips Adda, Find Us/social action when verified.
2. Hero — immediately communicate Fruit Minis + fruit chaat + Chips Adda. Hero visual should be food/cart-led, not abstract UI.
3. Two Cravings — editorial split introducing Fresh Fruit Chaat and Crunchy Chips Adda.
4. Fruit Chaat — visual-first feature area. Do not invent variants/prices. Structure data so they can be added later.
5. Chips Adda — explain "bring/pick your bag -> choose level -> we load it with toppings" and show verified ₹39/₹59/₹79/₹109 options.
6. How Chips Adda Works — concise 3-step interaction.
7. Gallery / From the Cart — use supplied imagery initially; architecture should allow later Instagram/reel assets.
8. Visit / Contact — render only verified address, map, hours, WhatsApp/phone. Until provided, social CTA can be primary.
9. Footer — Fruit Minis, tagline, social links once supplied.

Do not create fake About, press, reviews or stats sections just to fill space.
