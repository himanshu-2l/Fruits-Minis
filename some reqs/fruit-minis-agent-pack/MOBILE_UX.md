# Mobile UX

Design at 390px first, then expand.
- No horizontal overflow.
- Tap targets >= 44px.
- Menu/prices readable without zoom.
- Hero communicates offering within first viewport or immediately after it.
- Sticky action is allowed only when a real contact/location action exists.
- Avoid oversized headings that leave only 1-2 words per line.
- Images should crop intentionally rather than simply shrink desktop compositions.
- Test 320, 375/390, 430, 768, 1024 and >=1440 widths.
