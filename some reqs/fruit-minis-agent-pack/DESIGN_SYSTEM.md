# Design System

## Color tokens
Derive final accessible values from the supplied brand assets. Suggested semantic roles, not mandatory hex values:
- `brand-leaf`: saturated fruit green
- `brand-lime`: bright fresh highlight
- `brand-citrus`: orange
- `brand-mango`: warm yellow
- `ink`: near-black/charcoal
- `paper`: warm off-white
- `spice`: controlled red/pink accent

Verify WCAG contrast for text and controls.

## Typography
Use a bold condensed/display face for headlines/signage and a highly legible sans for body/UI. Do not use more than two families. Use variable fonts where practical and self-host/package correctly if licensing permits.

## Shape language
Mix sharp editorial blocks with selective organic fruit-inspired curves. Do not make every container a rounded rectangle.

## Motion
Fast, tactile and food-like: ingredient pop-ins, restrained squash/bounce, clipped reveals, marquee only where it serves content. Respect `prefers-reduced-motion`.

## Spacing
Use a consistent fluid scale with `clamp()`. Favor generous whitespace between energetic sections.
