# Fruit Minis — Coding Agent Handoff Pack

Build a high-character, mobile-first website for **Fruit Minis**, a street-food cart serving fruit chaat and a "Chips Adda" bring-your-own-bag snack concept.

## Source of truth
Only use verified facts in `BUSINESS_CONTEXT.md` and the supplied assets. Do not invent address, phone, hours, reviews, social proof, delivery claims, or fruit-chaat pricing.

## Start here
1. Read `MASTER_PROMPT.md`.
2. Read every root spec before coding.
3. Inspect `/assets` visually.
4. Execute prompts in `/prompts` in numerical order.
5. Run the acceptance checklist before considering the site finished.

Recommended stack: Next.js + TypeScript + Tailwind CSS + Motion/Framer Motion. Prefer native CSS for simple motion. Keep dependencies lean.
